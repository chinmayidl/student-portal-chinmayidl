# 🎓 Student Service Portal

A full-stack **Student Service Portal** developed for Computer Science Engineering students.  
This project provides a centralized platform where students can view services, submit queries, and administrators can manage requests.

---

# 🚀 Features

- Home Page
- About Page
- Services Page
- Contact Page
- Admin Dashboard
- Login Page
- Responsive UI Design
- JSON Database
- REST API (GET & POST)
- Dynamic Data Handling
- Git Branch Workflow
